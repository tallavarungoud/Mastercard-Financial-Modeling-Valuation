# Mastercard Financial Modeling & Valuation (Excel Project)

## Project Overview

This project presents a comprehensive financial modeling and valuation analysis of Mastercard Inc. built using Microsoft Excel.

The model analyzes historical financial performance, forecasts future financial statements, and estimates intrinsic value using multiple valuation techniques.

The objective is to demonstrate practical skills in financial modeling, corporate valuation, financial statement analysis, forecasting, and investment analysis.

---

## Company Overview

**Mastercard Inc.** is a global technology company in the payments industry that connects consumers, financial institutions, merchants, governments, and businesses worldwide.

The company enables electronic payments and digital transaction processing and provides a range of payment solutions and financial technology services.

---

## Project Objectives

- Build a structured financial model using historical financial data.
- Analyze financial performance using key financial metrics and ratios.
- Forecast future financial performance based on defined assumptions.
- Estimate intrinsic value using multiple valuation methods.
- Compare financial performance with industry peers.
- Evaluate valuation sensitivity to key financial assumptions.
- Develop an investment thesis based on the model's valuation outputs.

---

## Model Structure

### 1. Assumptions

The assumptions section contains key inputs used for financial forecasting and valuation, including:

- Revenue growth assumptions
- Operating margin assumptions
- Tax rate assumptions
- Capital expenditure assumptions
- Discount rate inputs
- Terminal growth assumptions

### 2. Financial Statements

The model incorporates three-statement financial modeling:

- Income Statement
- Balance Sheet
- Cash Flow Statement

The financial statements support historical analysis and forward-looking financial projections based on model assumptions.

### 3. Financial Analysis

The model includes financial performance analysis covering:

- Common-size analysis
- Profitability ratios
- Liquidity ratios
- Efficiency ratios
- Credit ratios
- Historical financial growth trends

### 4. Cost of Capital (WACC)

The model estimates the Weighted Average Cost of Capital (WACC) using inputs such as:

- Risk-free rate
- Market risk premium
- Beta estimation
- Cost of debt

The DCF valuation sheet uses a WACC assumption of **9.48%**. The workbook contains a slightly different WACC result on the separate WACC sheet, so the assumptions should be reconciled before treating the valuation as definitive.

### 5. Beta and Regression Analysis

The project includes regression analysis to estimate Mastercard's beta using historical market return data.

Beta is used as an input in evaluating the company's cost of equity and overall cost of capital.

### 6. Valuation Methods

Multiple valuation approaches are included to estimate Mastercard's intrinsic value:

- Discounted Cash Flow (DCF) Valuation
- Dividend Discount Model (DDM)
- Free Cash Flow to Firm (FCFF) Valuation
- Free Cash Flow to Equity (FCFE) Valuation
- Relative Valuation and Comparable Company Analysis

Using multiple methods enables comparison of valuation outputs under different approaches and assumptions.

### 7. Forecasting and Projections

The model analyzes historical financial performance for **2020–2024** and includes a five-year forecast horizon for **2025–2029**.

The DCF valuation sheet uses a **10% revenue growth assumption** and a **3% terminal growth assumption**.

Forecast results depend on the assumptions and inputs used in the workbook.

### 8. Industry and Competition Analysis

The project includes industry and competitor analysis to support financial benchmarking and comparison of Mastercard's performance with other companies in the payments industry.

### 9. Sensitivity and Scenario Analysis

Sensitivity and scenario analysis evaluate how changes in key assumptions can affect valuation results.

Variables considered include:

- Revenue growth
- Discount rate and WACC
- Operating margins
- Terminal growth rate
- Bull-case, base-case, and bear-case scenarios

The workbook contains differing valuation outputs across methods and scenario sheets. These differences are important considerations when interpreting the model.

### 10. Investment Thesis and Risk Analysis

The project includes an investment thesis, investment recommendation, and risk analysis sections to organize the valuation findings and assess relevant financial assumptions and risks.

The conclusions are based on the model's assumptions and outputs and should not be interpreted as guaranteed investment outcomes.

## Key Valuation Output

| Valuation Metric | Model Output |
|---|---:|
| Blended valuation target | **$389.91 per share** |
| Assumed reference price | **$450.00 per share** |
| Implied downside | **13.35%** |

The model's blended valuation estimate of **$389.91 per share** indicates an implied downside of **13.35%** relative to the assumed reference price of **$450.00 per share**.

**Calculation:**

\[
\frac{450.00 - 389.91}{450.00}\times100
= 13.35\%
\]

The result is rounded to two decimal places.

**Valuation note:** The $450.00 reference price is an assumption in the workbook, not a verified live market quote. Other valuation methods and scenario sheets contain different outputs. Therefore, $389.91 is presented as the model's blended valuation estimate, not a fully reconciled or definitive fair value. The valuation outputs should be reconciled before being used to support a final investment recommendation.
